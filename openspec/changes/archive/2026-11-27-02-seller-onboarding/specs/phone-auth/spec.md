# Spec Delta

## Purpose

Позволяет продавцу войти по российскому номеру через одноразовый код и
получить сессию для работы в seller admin.

## ADDED Requirements

### Requirement: Запрос одноразового кода

Система SHALL принимать российский номер телефона, отправлять OTP и
отвечать одинаково независимо от того, зарегистрирован номер или нет.

#### Scenario: Код отправлен

- **WHEN** продавец отправляет валидный российский номер
- **THEN** система отправляет OTP и возвращает 200 без признака
  существования аккаунта

#### Scenario: Невалидный номер

- **WHEN** номер не соответствует российскому формату
- **THEN** система возвращает 400 и не отправляет код

#### Scenario: Слишком много запросов

- **WHEN** с одного IP или номера превышен лимит запросов кода
- **THEN** система возвращает 429 и не отправляет новый код

### Requirement: Проверка кода и сессия

Система SHALL проверять OTP, создавать пользователя при первом входе и
выдавать httpOnly-сессию.

#### Scenario: Успешный вход

- **WHEN** продавец вводит верный непросроченный код
- **THEN** система выдаёт httpOnly-cookie сессии и возвращает профиль

#### Scenario: Неверный или просроченный код

- **WHEN** код неверен, просрочен или превышены попытки
- **THEN** система возвращает 401 без подсказки, что именно не сошлось

### Requirement: Текущая сессия и выход

Система SHALL отдавать профиль по действующей сессии и очищать сессию
при выходе.

#### Scenario: Профиль по сессии

- **WHEN** клиент запрашивает `/auth/me` с действующей cookie
- **THEN** система возвращает пользователя

#### Scenario: Нет сессии

- **WHEN** клиент запрашивает защищённый ресурс без cookie
- **THEN** система возвращает 401

#### Scenario: Выход

- **WHEN** клиент вызывает logout
- **THEN** cookie сессии очищается, повторный `/auth/me` возвращает 401

### Requirement: Безопасность OTP

Система SHALL хранить только хеш OTP с TTL и ограничением попыток, не
логировать телефон и код и не включать dev-адаптер в production.

#### Scenario: Истёкший код

- **WHEN** с момента отправки прошло больше TTL
- **THEN** код не принимается

#### Scenario: Dev-адаптер в production

- **WHEN** `NODE_ENV=production` и выбран dev-адаптер SMS
- **THEN** приложение падает на старте, а не отправляет коды в лог
