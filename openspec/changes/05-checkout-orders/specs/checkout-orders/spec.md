# Spec Delta

## Purpose

Позволяет авторизованному покупателю оформить заказ продавцу и видеть
свои заказы, а продавцу — заказы своего магазина.

## ADDED Requirements

### Requirement: Сессия покупателя

Система SHALL использовать существующую телефонную сессию для checkout и
чтения заказов; guest-checkout запрещён.

#### Scenario: Успешный вход покупателя

- **WHEN** покупатель подтверждает OTP и открывает checkout
- **THEN** он может оформить заказ; login нейтрален по роли

#### Scenario: Нет сессии

- **WHEN** checkout или чтение заказов идёт без действующей cookie
- **THEN** система возвращает 401 и не создаёт/не отдаёт заказ

#### Scenario: Возврат после входа

- **WHEN** неавторизованный покупатель открывает checkout
- **THEN** система ведёт на login и после входа возвращает на checkout

### Requirement: Checkout

Система SHALL создавать заказ на каждый магазин из доступных товаров.

#### Scenario: Успешный checkout

- **WHEN** авторизованный покупатель отправляет 1–50 доступных товаров
- **THEN** создаётся заказ на каждый магазин со snapshot названия/цены и
  статусом `new`

#### Scenario: Товар недоступен

- **WHEN** хотя бы один товар не published или магазин не published
- **THEN** система возвращает 409 `product_unavailable` и не создаёт
  частичный заказ

#### Scenario: Невалидный список

- **WHEN** список пуст, содержит дубли или больше 50 позиций
- **THEN** система возвращает 400 и не создаёт заказ

#### Scenario: Слишком частый checkout

- **WHEN** пользователь превышает лимит checkout
- **THEN** система возвращает 429 и не создаёт заказ

#### Scenario: Повтор checkout

- **WHEN** клиент повторяет checkout с тем же `clientCheckoutId`
- **THEN** система возвращает существующие заказы (включая несколько
  магазинов) и не создаёт дубли

### Requirement: Свои заказы покупателя

Система SHALL показывать покупателю только его заказы.

#### Scenario: Список покупателя

- **WHEN** покупатель запрашивает свои заказы
- **THEN** он видит только заказы своего `user_id`

#### Scenario: Чужой заказ

- **WHEN** покупатель запрашивает заказ другого покупателя
- **THEN** система возвращает 404

### Requirement: Заказы продавца

Система SHALL показывать продавцу только заказы его магазина.

#### Scenario: Список продавца

- **WHEN** продавец открывает заказы
- **THEN** он видит заказы своего магазина, новые первыми

#### Scenario: Нет магазина

- **WHEN** авторизованный пользователь без магазина открывает seller orders
- **THEN** система возвращает пустой список и ссылку на onboarding

#### Scenario: Чужой заказ магазина

- **WHEN** продавец запрашивает заказ чужого магазина
- **THEN** система возвращает 404

### Requirement: Приватность заказа

Система SHALL показывать телефон и комментарий заказа только покупателю
и продавцу этого заказа и не писать их в логи.

#### Scenario: Публичного доступа нет

- **WHEN** заказ запрашивается без сессии или чужим пользователем
- **THEN** система возвращает 401/404 и не раскрывает телефон/комментарий

#### Scenario: Логи

- **WHEN** checkout или чтение заказа завершается ошибкой
- **THEN** лог содержит только id/status/error code, без телефона,
  комментария и OTP
