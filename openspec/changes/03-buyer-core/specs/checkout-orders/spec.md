# Spec Delta

## Purpose

Позволяет авторизованному покупателю оформить заказ продавцу и видеть
свои заказы, а продавцу — заказы своего магазина.

## ADDED Requirements

### Requirement: Checkout требует сессию

Система SHALL создавать заказ только для авторизованного покупателя.

#### Scenario: Нет сессии

- **WHEN** checkout вызывается без действующей cookie
- **THEN** система возвращает 401 и не создаёт заказ

#### Scenario: Успешный checkout

- **WHEN** авторизованный покупатель отправляет доступные товары
- **THEN** создаётся заказ на каждый магазин со snapshot названия/цены
  и статусом `new`

### Requirement: Валидация товаров

Система SHALL проверять доступность товаров и считать итог на сервере.

#### Scenario: Товар снят с публикации

- **WHEN** хотя бы один товар больше не published или магазин draft
- **THEN** система возвращает 409 и не создаёт частичный заказ

#### Scenario: Цена изменена

- **WHEN** цена товара изменилась после добавления в корзину
- **THEN** заказ фиксирует актуальную серверную цену

### Requirement: Свои заказы покупателя

Система SHALL показывать покупателю только его заказы.

#### Scenario: Список покупателя

- **WHEN** покупатель запрашивает свои заказы
- **THEN** он видит только заказы своего `user_id`

#### Scenario: Чужой заказ

- **WHEN** покупатель запрашивает заказ другого покупателя
- **THEN** система возвращает 404

### Requirement: Заказы продавца

Система SHALL показывать продавцу только заказы его магазина.

#### Scenario: Список продавца

- **WHEN** продавец открывает заказы
- **THEN** он видит заказы своего магазина, новые первыми

#### Scenario: Чужой заказ магазина

- **WHEN** продавец запрашивает заказ чужого магазина
- **THEN** система возвращает 404
