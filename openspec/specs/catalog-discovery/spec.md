# catalog-discovery Specification

## Purpose

Позволяет покупателю находить товары в общем каталоге через поиск,
сортировку и постраничный просмотр.

## Requirements

### Requirement: Поиск товаров

Система SHALL искать published-товары published-магазинов по названию
товара или магазина.

#### Scenario: Поиск по названию

- **WHEN** покупатель передаёт `q` с частью названия товара
- **THEN** система возвращает только подходящие опубликованные товары

#### Scenario: Ничего не найдено

- **WHEN** по запросу нет подходящих товаров
- **THEN** система возвращает 200 с пустым списком и `total: 0`

#### Scenario: Скрытые товары

- **WHEN** поиск совпадает с draft/hidden товаром или draft-магазином
- **THEN** такой товар не попадает в выдачу

### Requirement: Сортировка

Система SHALL сортировать выдачу по новизне или цене.

#### Scenario: Сортировка по цене

- **WHEN** покупатель выбирает `price_asc` или `price_desc`
- **THEN** товары упорядочены по цене в копейках с устойчивым tie-break

#### Scenario: Новые сначала

- **WHEN** покупатель выбирает `newest`
- **THEN** товары упорядочены по дате создания, новые первыми

### Requirement: Пагинация

Система SHALL отдавать каталог страницами с ограничением размера.

#### Scenario: Первая страница

- **WHEN** покупатель открывает каталог без параметров
- **THEN** система возвращает page=1, pageSize=100, total и hasMore

#### Scenario: Слишком большой размер

- **WHEN** `pageSize` больше 100, `pageSize` ≤ 0 или `page` меньше 1
- **THEN** система возвращает 400 и не строит выдачу

#### Scenario: Невалидный поиск или сортировка

- **WHEN** `q` длиннее 100 или `sort` вне `newest|price_asc|price_desc`
- **THEN** система возвращает 400 и не строит выдачу
