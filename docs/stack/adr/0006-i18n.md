# ADR 0006: i18n runtime copy

> **Context:** `status: accepted` · `updated: 2026-11-28` · `owner: Architect` ·
> `sprint: 4` · `task: S4-1` · `change: No spec change: i18n refactor` ·
> links: [sprint plan](../../tasks/04-i18n.md) ·
> [text review](../../tasks/text-review.md) · [copywriting](../../design/content.md)

## Контекст

Пользовательские тексты разбросаны по 33 production-файлам web (405, из них 3 index meta — allowlist; миграция 402
фрагментов), плюс SMS-шаблон, status labels и meta. Copywriter review и
anti-slop нельзя надёжно удержать на разбросанных строках. Владелец
выбрал `i18next`/`react-i18next` и 100% покрытие runtime-текстов.

## Решение

- `packages/i18n` (`@localhand/i18n`) с `i18next` core; `resources/ru.ts`
  — единственный источник runtime-текстов.
- Web: `react-i18next`, инициализация в `main.tsx`; API/SMS: тот же пакет
  без React.
- Один `ru`; typed keys через `CustomTypeOptions`; plural — i18next
  (`_one/_few/_many`), даты/деньги — `Intl`.
- 100% gate: `scripts/check-i18n.mjs` сканирует production web/API/shared
  на кириллицу вне каталога; baseline до миграции, пустой к закрытию;
  `pnpm check:i18n` в `verify`.
- Исключения: `apps/web/index.html` meta/title (static HTML, 3 строки),
  тесты/e2e, seed, provider payload (CDEK `statusName`), комментарии;
  причина в allowlist. `index.html` не мигрируется в S4-3.
- Зависимости: `@localhand/i18n` может импортировать типы из
  `@localhand/shared`; `shared` не импортирует i18n; web/api → i18n.

## Альтернативы

- Свой typed catalog без зависимости — проще, но владелец выбрал i18next.
- FormatJS/ICU — больше тулинга для одного языка.
- Оставить строки в JSX — не даёт 100% gate и единого места.

## Последствия

- Две новые runtime-зависимости: `i18next`, `react-i18next`; версии
  фиксируются lockfile, обновление — отдельным PR.
- Все текстовые PR теперь меняют `packages/i18n/resources/ru.ts`; JSX
  без кириллицы.
- Тесты/локаторы читают каталог/значения; baseline временно допускает
  старые строки, финальный gate — строгий.
- Откат: revert PR S4-1…S4-5; `@localhand/i18n`/зависимости уходят,
  строки возвращаются из git; baseline/ADR — часть revert.

## Проверка

- `pnpm verify` + `pnpm check:i18n`; unit `t`/plural; check-script fixture.
- 100% отчёт: 0 кириллицы вне каталога (кроме allowlist).
- e2e/axe после миграции W1/W2.
