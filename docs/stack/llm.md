# LLM для AI-агента

Решение 2026-11-27: **DeepSeek V4.1 Flash 1017 через российский
инференс-провайдер**, основной кандидат — Selectel Token Factory,
запасной — Cloud.ru Evolution Foundation Models. Прямой API DeepSeek
(api.deepseek.com) для продуктового агента с ПДн не используется.

## Почему DeepSeek V4.1 Flash

- Открытые веса MIT, сильные агентные бенчмарки, 1 млн токенов
  контекста, поддержка изображений.
- Tool calls / function calling, JSON output, OpenAI-совместимый API.
- Дешёвые токены по сравнению с зарубежными frontier-моделями.
- Доступен в РФ через провайдеров, которые обрабатывают запросы в
  российских ЦОД, — это снимает главный риск 152-ФЗ.

## Провайдеры

| Провайдер | Модель / API | Цена, ₽ за 1 млн вход/выход | Данные | Комментарий |
|---|---|---|---|---|
| Selectel Token Factory | `deepseek-v4.1-flash-1017`, `https://api.tf.selcloud.ru/v1` | 243,2 / 486,4; cached 58,7 | Российские ЦОД; промпты не хранятся и не идут на обучение, только техническая статистика | Основной выбор: явно заявлена обработка в РФ |
| Cloud.ru Evolution Foundation Models | `deepseek-ai/DeepSeek-V4-Flash` (ревизия V4.1), `https://foundation-models.api.cloud.ru/v1` | 64,94 / 194,81 | Заявлены серверы в РФ; часть моделей партнёрские — место обработки подтвердить | Дешевле, но требует подтверждения договора/резидентности |
| Direct DeepSeek API | `deepseek-flash`, `https://api.deepseek.com` | ~$0,15–0,30 / $0,60–1,20 (off-peak/peak) | За пределами РФ | Только для не-PII задач или прототипа; для продукта с ПДн — нет |
| Self-hosted | Веса V4.1 Flash, vLLM | Стоимость GPU | Свой контур | Полный контроль, но 160+ ГБ весов и GPU-кластер; не для v1 |

Selectel: модель 1017 — октябрьское обновление V4.1 Flash, MoE,
1 048 576 токенов контекста, зрение, скорость ~117 ток/с. Пример
стоимости: 50 000 входных + 2 000 выходных токенов ≈ 13 ₽ без кэша,
≈ 5,8 ₽ при 40 000 токенов в кэше.

Cloud.ru: дешевле, OpenAI-совместимый API, договор с ООО «Облачные
технологии», закрывающие документы, НДС. Перед использованием в проде
письменно подтвердить, что конкретная модель обрабатывается в РФ, а не
является партнёрской с зарубежным бэкендом.

## Интеграция

- Один адаптер `LlmProvider` в API: `chat(messages, tools, responseFormat)`.
- Конфиг: `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, `LLM_MAX_TOKENS`,
  `LLM_TIMEOUT_MS`.
- Selectel: `base_url=https://api.tf.selcloud.ru/v1`,
  `model=deepseek-v4.1-flash-1017`.
- Cloud.ru: `base_url=https://foundation-models.api.cloud.ru/v1`,
  `model=deepseek-ai/DeepSeek-V4-Flash`.
- Провайдер не знает о ролях и правах: permissions проверяет наш tool
  gateway на каждый вызов, а не модель.
- Промпты и ответы не логировать целиком; хранить только метаданные
  (токены, latency, tool name, статус), без ПДн.
- Перед отправкой — redaction/Guardrails: телефоны, адреса, ФИО, email,
  номера заказов заменяются на плейсхолдеры, если модель не должна их
  видеть. Для операционных tools с PII использовать только провайдера с
  подтверждённой обработкой в РФ.

## Бюджет

- Лимит на спринт и на магазин; soft-stop при 70%, hard-stop при 100%.
- Считать по `usage` каждого ответа, писать в `.scrum/budget.json` или
  отдельную таблицу `llm_usage`.
- Кэшировать системный промпт и описания tools: это основная экономия.
- Для тяжёлых задач (анализ длинного каталога) — отдельный лимит и
  предупреждение в чате.

## Риски

- Провайдер может изменить модель/цену/лимиты; адаптер и fallback
  обязательны.
- Cloud.ru может оказаться партнёрским прокси; без письменного
  подтверждения PII туда не отправлять.
- Прямой DeepSeek API дешевле, но данные уходят за границу; для ПДн —
  запрещено.
- Prompt injection и ошибочные tool calls: серверная проверка прав,
  подтверждение опасных действий, аудит.
- Галлюцинации в текстах описаний: человек подтверждает публикацию.

## Открытые вопросы

1. Подписать договор с Selectel или Cloud.ru; получить подтверждение
   места обработки и отсутствия обучения на данных.
2. Замерить реальную стоимость на пилоте (описания товаров, поиск,
   операционные tools).
3. Проверить качество tool calling на русском и на схемах Local Hand.
4. Определить fallback: YandexGPT/GigaChat или второй российский
   провайдер DeepSeek.
5. Утвердить лимиты токенов на магазин/пользователя/спринт.
