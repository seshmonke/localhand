## Голос

| Параметр | Значение | Что значит |
|---|---:|---|
| Формальность | 7 | деловой, взрослый |
| Теплота | 5 | уважительный, живой |
| Энергия | 4 | спокойный, собранный |
| Орнамент | 2 | редкий образ |
| Конкретность | 9 | цифры, детали, сцены |
| Срочность | 1 | только реальный срок |
| Техничность | 3 | объясняем по-человечески |
| Юмор | 2 | сухая ирония |

Правила: одна мысль на абзац; глагол делает работу; конкретное
существительное вместо абстракции; факт вместо прилагательного; один
CTA; пауза — часть текста.

## Глоссарий

| Термин | Значение | Не писать |
|---|---|---|
| Local Hand | платформа и маркетплейс | «Локал Хэнд», «LH» в UI |
| Магазин | витрина продавца | «стор», «лавка» |
| Продавец | сторона, которая продаёт | «селлер», «мерчант» в UI |
| Покупатель | сторона, которая покупает | «клиент», «юзер» в UI |
| Заказ | покупка одного магазина | «ордер» |
| Оплата | действие покупателя | «транзакция» в UI |
| Доставка | способ получения | «шиппинг» |
| ПВЗ | пункт выдачи СДЭК | «постамат» (это другое) |
| Отправление | посылка продавца | «шипмент» |
| Трек | номер отслеживания | «трек-код» |

## Анти-слоп

- Кодекс: [copywriting.md](../../.opencode/skills/scrum-crew/references/copywriting.md).
- Проверка: `bash .opencode/skills/scrum-crew/scripts/slop-check.sh <files>`.
- Чёрный список, синтаксис и смысловые правила — в кодексе.
- Нет ложных обещаний: сроки, цены, гарантии — только с фактом.

## Text review gate

- Новый/изменённый пользовательский или публичный текст: Copywriter
  review не-автора + `slop-check`.
- В PR: ссылка на ревью или `No text change: <причина>`.
- Полная программа: [text-review.md](../tasks/text-review.md).
