# Адаптивность: mobile-first + полноценный десктоп

Решение 2026-11-27: одна React-кодовка, mobile-first, но десктоп — не
растянутый мобильный экран, а полноценная раскладка со своей навигацией,
плотностью и сценариями.

## Принцип

- **Mobile-first** — проектируем от 320 px: сначала главное действие,
  потом расширение.
- **Desktop-complete** — на десктопе доступны все функции, но
  организованы иначе: многоколоночный каталог, постоянные фильтры,
  таблицы, hover/focus, клавиатура.
- **Один код, разные раскладки.** Не два приложения и не отдельная
  десктопная сборка. Различие — в layout-компонентах и брейкпоинтах,
  не в бизнес-логике.
- **Ничего не скрывать на десктопе.** Если функция есть на мобильном,
  она есть и на десктопе; меняется только способ доступа.

## Брейкпоинты

| Ширина | Что происходит |
|---|---|
| 320–599 | Мобильный: одна колонка, нижняя навигация, шторки |
| 600–1023 | Планшет: 2–3 колонки, боковая навигация-иконки, фильтры в шторке |
| 1024–1279 | Десктоп: постоянная шапка, боковые фильтры, 3 колонки каталога |
| 1280–1439 | Широкий десктоп: 4 колонки, таблицы, split-view в админке |
| 1440+ | Контейнер `max-width` 1440–1536 px, не бесконечная ширина |

Числа — рабочий ориентир; финальные проверить на живых экранах. База:
WCAG 2.2 Reflow — 320 CSS px без горизонтальной прокрутки.

## Мобильные паттерны

- Нижняя навигация: каталог, поиск, корзина, профиль.
- Одна колонка; фильтры и сортировка — в bottom sheet.
- Sticky-действие внизу экрана (купить/оплатить), safe-area.
- Тач-зоны ≥ 44×44 px; поля ввода ≥ 16 px, чтобы iOS не зумил.
- Карточка товара — вертикальная, крупное фото, цена и CTA.
- Админка: быстрые действия и статусы; таблицы — карточками или
  горизонтальным скроллом внутри блока.

## Десктопные паттерны

- Постоянная шапка: логотип, поиск, категории, корзина, профиль.
- Каталог: 3–4 колонки, фильтры слева, сортировка сверху, пагинация.
- Карточка товара: галерея слева, информация и CTA справа.
- Админка: sidebar, таблицы с sticky-header, inline-edit, bulk-actions,
  split-view «список → деталь», горячие клавиши.
- Hover/focus-состояния обязательны; фокус видим и не теряется.
- Клики мышью — 32–40 px, но не меньше 24 px (WCAG 2.5.8).
- Максимальная длина строки 60–75 символов; контент не растягивается
  на весь монитор.

## Компоненты

- Один компонент, две раскладки: `ProductCard` меняет пропорции и
  количество колонок, а не дублируется.
- Layout-примитивы: `PageShell`, `Container`, `Grid`, `Sidebar`,
  `BottomBar`, `Sheet` (мобильный) / `Popover` (десктоп).
- Навигация: mobile bottom bar и desktop header/sidebar используют одни
  и те же маршруты и права.
- Таблицы: на мобильном — карточки/скролл, на десктопе — таблица.
- Формы: на мобильном — полноэкранные шаги, на десктопе — колонка с
  боковой подсказкой.

## Контент и изображения

- `srcset`/`sizes` для фото товаров; lazy-loading ниже первого экрана.
- Соотношения сторон фиксированы, чтобы не было CLS.
- Лендинг: mobile — вертикальные секции, desktop — hero в две колонки,
  затем сетка преимуществ/категорий.
- Текст не обрезается до нечитаемого; перенос строк контролируется.

## Проверка

Матрица Playwright/ручной проверки:

- 320×568, 390×844, 768×1024, 1024×768, 1280×800, 1440×900.
- Ключевые сценарии: каталог → фильтр → карточка → корзина → оплата;
  продавец: товар → публикация; админ: таблица → модерация.
- Нет горизонтальной прокрутки на 320; фокус и клавиатура на десктопе;
  тач-зоны на мобильном; hover на десктопе.
- Проверять обе темы: светлую и тёмную.

## Антипаттерны

- Растянуть мобильную колонку на десктоп.
- Спрятать функцию на десктопе «потому что есть на телефоне».
- Отдельное десктопное приложение с другой логикой.
- Бесконечная ширина контента на 4K.
- Таблица, которая на мобильном уезжает за экран без альтернативы.
- Hover как единственный способ что-то узнать.

## Источники

- WCAG 2.2, 1.4.10 Reflow — 320 CSS px.
- WCAG 2.2, 2.5.8 Target Size (Minimum) — 24×24 CSS px.
- Apple Human Interface Guidelines — 44×44 pt.
- Material Design — адаптивные раскладки и брейкпоинты.
- NN/g — мобильная и десктопная навигация, таблицы, формы.
