# Бэклог

Весь пул задач без привязки ко времени. Порядок — приоритет.

Формат строки:

```
- [ ] P1. Короткий глагол: что сделать. Критерий: как проверить.
      Источник: откуда взялось. Спринт: —.
```

Метки:
- **P0** — блокирует главный сценарий, угрожает данным или безопасности.
- **P1** — частый сценарий или заметная масса без пользы.
- **P2** — остальное.

  магазин, товар из PostgreSQL через API. Критерий: preview показывает
  ≥3 товара, `/health` 200, `pnpm verify` зелёный. Источник: Init 0.4.
  Спринт: —.
- [ ] Создать GitHub-репозиторий, protected `main`, required checks,
  review-gate. Критерий: прямой push в `main` невозможен, PR требует
  не-автора. Источник: Init 0.3. Спринт: —.
- [ ] Закрыть юридический пакет: оферта, политика ПДн, правила
  платформы, уведомление РКН. Критерий: документы опубликованы,
  уведомление подано. Источник: `docs/legal/context.md`. Спринт: —.
- [ ] Реализовать auth только через российские сервисы (телефон/SMS,
  VK ID, Яндекс ID, Sber ID). Критерий: вход без Telegram/Google,
  сессия, rate-limit, тесты. Источник: 149-ФЗ. Спринт: —.
